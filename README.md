# 🧬 PharmaGuard AI  
### AI-Powered Pharmacogenomic Risk Assessment Platform

PharmaGuard AI is a full-stack clinical decision support system that analyzes patient **VCF genomic data** and predicts drug–gene interaction risks using:

- 🧬 CPIC Guidelines  
- ⚙️ Rule-Based Pharmacogenomic Logic  
- 🤖 AI-Generated Clinical Explanations  
- 📊 Structured Risk Scoring  

---

# 🚀 Project Overview

PharmaGuard enables clinicians and researchers to:

- Upload patient **VCF genomic files**
- Extract pharmacogenomic variants
- Map star alleles and diplotypes
- Assess drug-specific genetic risk
- Generate structured clinical recommendations
- Export professional JSON reports

# ⚙️ Installation

## 1️⃣ Clone Repository

bash
git clone https://github.com/Prer26/PharmaGuard-AI.git
cd PharmaGuard-AI


---

## 2️⃣ Backend Setup

bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload


Backend runs at:


http://localhost:8000

---

## 3️⃣ Frontend Setup

bash
cd frontend
npm install
npm run dev


Frontend runs at:

http://localhost:5173
